# Moving the live game from the Mac to the PC

Written 2026-11-02 11:40 Pacific. Status at 13:18: moved and live on the Windows
PC; see `STATE.md` for what was verified and "After it is verified" for what is
left. Why move: Ken wants to play Cities: Skylines II at the same time.

The first daemon run on Windows stalled at 66 pushed files, because Python
defaulted to cp1252. `bb_remote.py` now names UTF-8 itself, so step 6 works as
written, confirmed by a restart without `PYTHONUTF8` at 13:17.

## Rule that matters most

One live copy of the save, ever. Close the Mac game before starting the PC one.
Two copies overwrite each other through autosave and possibly Steam Cloud.

## Prepare the PC first (the game keeps earning meanwhile)

1. Install Steam, BitBurner, Git, Python 3.9 or later, Node, Claude Code. Do not
   start BitBurner yet.
2. Add a GitHub SSH key. Turn off line-ending conversion before cloning, because
   the daemon pushes these files into the game and CRLF would change every one:

   ```bash
   git config --global core.autocrlf false
   ```

   ```bash
   git clone git@github.com:waunder/BitBurner.git
   ```

3. In the clone, build the venv. There is no requirements file; these are the
   versions on the Mac:

   ```bash
   python -m venv .venv
   ```

   ```bash
   .venv\Scripts\python -m pip install websockets==15.0.1 websocket-client==1.9.0
   ```

4. Check the code before the game matters: `node --test *.test.js`.
5. Set BitBurner's Steam launch options to `--remote-debugging-port=9222`.

## Cut over

On the Mac:

1. Disable the hourly task `bitburner-bn15-progress`, so no run touches the game
   mid-move or edits `STATE.md` from the old copy.
2. Commit and push anything outstanding; `git status` should show only the
   untracked evidence and launchd log files.
3. In the game, Options, export the save, and copy that file to the PC. Also keep
   it in `saves/`. Do not rely on Steam Cloud: its local copy was last written
   05:56 on 2026-11-02, hours behind the game.
4. Quit BitBurner fully.
5. Stop the keep-alive service, then the daemon. The service must go first
   because it respawns the daemon:

   ```bash
   launchctl bootout gui/$(id -u)/com.bitburner.remote-api-monitor
   ```

   ```bash
   pkill -f 'bb_remote.py daemon'
   ```

On the PC:

6. Start the daemon from the clone. Leave this window open; nothing restarts it
   if it dies, because `tools/remote_api_monitor.py` is Mac-only (`fcntl`, launchd):

   ```bash
   .venv\Scripts\python tools\bb_remote.py daemon --port 12526 --control-port 12527
   ```

7. Start BitBurner. If Steam reports a save conflict, either choice is fine,
   because the next step overwrites it.
8. Options, import the exported save, and confirm.
9. Options, Remote API: 127.0.0.1, port 12526, plain WebSocket, Connect.
10. Start Claude Code in the clone and say: "Read docs/pc-move-2026-11-02.md and
    verify the move."

## Going back

Until the PC game has run and saved progress you want to keep, the Mac can
resume. After that, export from the PC first and import on the Mac. Quit the PC
game and stop its daemon, then:

```bash
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.bitburner.remote-api-monitor.plist
```

Start BitBurner on the Mac and re-enable the hourly task.
