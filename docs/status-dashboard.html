root cause found + fixed 2026‑08‑11 16:40
Found the real reason the farm looked stuck — not the hack/grow policy

You were right that something needed fixing, just not the part it looked like. "No hacking while empty" is deliberate and correct — hacking a near‑empty server steals almost nothing while still adding cleanup work. The actual bug, found by reading the game's real numbers directly: foodnstuff's money level was swinging back and forth across a mode boundary every single 10‑second tick, for over 4 hours straight. Each swing forced every host to kill and restart its grow/weaken work — and that work takes 13‑16 seconds to finish, longer than the 10‑second tick, so it was being killed before any single run could ever complete. The weighting logic was fine the whole time; it just never got to run long enough to matter. Widened the boundary's buffer so this specific swing can't cross it anymore — confirmed live, the flip-flopping stopped immediately after. A more permanent fix (don't restart work that hasn't had time to finish, regardless of why) is scoped and queued next.

bug fix + tests 2026‑08‑11 15:45
Found and fixed why file edits stopped reaching the game after today's move

You asked for a more robust regime after the earlier silent failure — this is that, applied directly to the bug that caused it. Root cause: the background sync process remembered this project's old folder location as a one-time snapshot taken when it started, and a folder rename doesn't update a snapshot like that, even though the process itself kept running fine otherwise. Fixed so it re-checks the real location on every single file, every time, so a future move like today's can't cause a repeat. Also added a loud warning that would surface immediately in a status check if this class of problem ever happens again, instead of a quiet log line nobody's watching. Backed by 8 new automated tests that reproduce today's exact incident and confirm the fix holds; all 34 tests in the suite pass. The fix is written, tested, and saved — it takes effect on the next restart, which is the item below.
