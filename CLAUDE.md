# BitBurner project instructions

This file is retained as a compatibility pointer for tools that look for
`CLAUDE.md`. It is not an independent source of instructions.

Use `AGENTS.md` as the sole project operating guide, `STATE.md` as the current
session handoff, `docs/Codex-todo.md` for current implementation work, and
`docs/processes.md` for the script map. The repo is a tree (`core/`, `profiles/<name>/`) while
the game keeps flat file names; `sync_manifest.json` (generated by `tools/profile.py`) maps one
to the other, and files pulled from the game land in `runtime/`; see
`docs/architecture-profiles.md`. The previous long-form guide is
preserved at `docs/archive/context-cleanup-2026-10-16/CLAUDE-before-cleanup.md`
for historical reference only. Do not follow its stale environment, approval,
communication, or Remote API claims.
